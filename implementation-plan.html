01 — Overview

What we are building

This plan operationalizes the ProjectWatch Rwanda concept proposal. It delivers an MVP focused on road construction monitoring: a platform that ingests satellite imagery, detects physical change with AI, and surfaces project health to government and development-partner users.

The work is organized into three sequential phases over nine months, each with explicit deliverables, exit criteria, and effort estimates. Phase gates prevent over-investment before validation.

Success Criteria

  • A registered project with a GIS boundary renders on a live map.
  • At least two satellite passes per monitored site are processed automatically.
  • The AI engine produces a change score with a confidence level per observation.
  • An amber/red project health signal triggers an alert to the assigned stakeholder.
  • A pilot cohort of ≥ 5 real road projects is monitored for ≥ 8 weeks with stakeholder feedback.

02 — Assumptions & Constraints

What we are planning against

Assumptions

  • Free/open satellite feeds (Sentinel-1/2, Landsat) are sufficient for MVP.
  • A small technical team (2–4) can deliver the MVP within budget.
  • Cloud credits or a modest VPS cover compute for prototyping.
  • At least one partner agency can supply pilot project boundaries.

Constraints

  • No proprietary data contracts in MVP scope.
  • Cloud cost must stay within the estimate envelopes.
  • AI accuracy validated against manual ground truth, not production SLAs.
  • Rwanda-specific context (workflows, geography) shapes UX.

04 — Phase 1

Foundation · Months 0–3

Stand up the platform backbone so that a project can be registered, located on a map, and kept current with satellite imagery — without yet declaring intelligence.

Deliverables

  • Platform architecture & repository scaffolding (Next.js + Node.js + PostGIS)
  • Project Intelligence Registry with GIS boundary management
  • Timeline & milestone tracking per project
  • Automated satellite image retrieval (Sentinel-1/2, Landsat)
  • Image processing pipeline (Python + GDAL + Rasterio)
  • Geospatial storage: PostGIS (vector) + object storage (raster)
  • OGC map service (GeoServer) + initial dashboard (MapLibre GL)

05 — Phase 2

Intelligence Layer · Months 3–6

Convert raw imagery into monitored intelligence: detect change, score progress, classify risk, and generate reports.

Deliverables

  • AI change detection engine (land/construction/vegetation change)
  • Progress scoring vs. defined milestones
  • Risk classification (green / amber / red)
  • Automated reporting & alerts
  • AI Project Assistant (natural-language queries)

Modeling Approach

Initial change-detection baseline

  • Coregister Sentinel-2 pairs; compute NDVI / indices diff
  • Sentinel-1 SAR backscatter change for cloud-free signal
  • Threshold + lightweight CV model → change score & confidence
  • Compare observed activity to milestone schedule → risk class

Example Assistant Query

# Natural-language access layer
"Show projects with no detected activity in the last 60 days."
  → filter projects where latest_change_score < threshold
  → within observation window > 60d

Exit Criteria

Gate

Change scores correlate with manually labeled ground truth on a held-out set (target agreement ≥ 70% at MVP tolerance), and an amber signal produces an alert.

06 — Phase 3

Pilot Deployment · Months 6–9

Run the platform against real road projects, validate accuracy with stakeholders, and feed learnings back into the models.

Deliverables

  • Onboard ≥ 5 pilot road projects with partner agency boundaries
  • Continuous monitoring for ≥ 8 weeks
  • Accuracy validation against field/photo evidence
  • Stakeholder feedback collection & usability iteration
  • Model improvements from pilot signals

Pilot Cadence

Weeks 1–2 · Onboarding & trainingW1–2
Weeks 3–8 · Active monitoring & check-insW3–8
Weeks 9–10 · Validation & feedback synthesisW9–10

Exit Criteria

Gate

A written pilot report confirms monitored coverage, measured accuracy, stakeholder satisfaction, and a prioritized backlog for commercial scaling.
