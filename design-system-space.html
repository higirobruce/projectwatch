Space

The interface language for the intelligence platform — a satellite ground-station HUD. Mostly dark (deep space), with a light optical-review view. This system governs the web application (dashboard, intelligence UI, assistant). Narrative docs keep Paper & Ink.

Usage

Adopt in the web app

The web application consumes these tokens as CSS custom properties. Default theme is data-theme="dark" on <html>; the optical-review mode sets data-theme="light". Keep Paper & Ink only for narrative docs.

<!-- index.html -->
<html data-theme="dark">
  <link rel="stylesheet" href="space.css">
  <button class="btn btn-primary">Run analysis</button>
  <span class="badge badge-amber">Amber</span>
